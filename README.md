My personal portfolio — cloud-native and full-stack development projects, career history, and skills.

Live: [https://ghopperjr.github.io/PaulTaripePortfolio](https://ghopperjr.github.io/PaulTaripePortfolio)

## Built with

React, TypeScript, Sass, and Material UI. Based on [yujisatojr/react-portfolio-template](https://github.com/yujisatojr/react-portfolio-template).

## Running locally

```bash
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).

## Deployment

```bash
npm run deploy
```

Builds the app and publishes it to the `gh-pages` branch, served at the `homepage` URL in `package.json`.
